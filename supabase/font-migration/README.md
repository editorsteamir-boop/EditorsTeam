# Fonto Supabase Migration

این پوشه برای انتقال بانک فونت Fonto به Supabase Storage است.

مراحل:
1. فونت‌های استخراج شده APK را داخل پوشه fonts قرار دهید.
2. مقادیر Supabase را در env وارد کنید.
3. migrate-fonts.js را اجرا کنید.

فونت‌ها به صورت lazy load در بخش Font Lab مصرف می‌شوند و در GitHub نگهداری نمی‌شوند.
